# Azure Automanage and VM Best Practice Enforcement

## 1. Abstract
Azure Automanage and VM Best Practice Enforcement is a cloud automation project designed to simplify the management of Azure Virtual Machines. The project uses Azure Policy to enforce recommended configurations and best practices on VMs. Azure Automanage helps with automated VM management, while remediation helps correct non-compliant resources. Azure Monitor is used to observe VM performance and operational status. This solution reduces manual configuration, improves compliance, and provides centralized monitoring of virtual machines.

- Az PowerShell Module
- GitHub for Code Repository
